# หน้าแรกและภาษา TH/EN

- ผู้ที่ยังไม่เข้าสู่ระบบ เปิด `/` แล้วไป `/login` โดยตรง ผู้ที่มี session ไป `/learn`
- หน้าแนะนำเดิมยังเปิดได้ที่ `/welcome` จากลิงก์เกี่ยวกับ EngThai ใต้หน้า Login
- ภาษาเริ่มต้นของแอปเป็นไทย มีปุ่ม TH/EN ที่หน้า Login และแถบด้านบนของพื้นที่เรียนรู้
- ภาษาที่เลือกเก็บใน cookie `engthai-language` อายุหนึ่งปี และอ่านจาก server ตอนเปิดหน้า จึงไม่ต้องโหลดหน้าอังกฤษก่อนสลับเป็นไทย
- การสลับภาษาอัปเดต `html lang` และสถานะปุ่มสำหรับโปรแกรมอ่านหน้าจอ โดยไม่ล้างฟอร์ม คำตอบ หรือผลการเรียน
- เมนู Dashboard ชื่อบทเรียน เป้าหมายวันนี้ คะแนนสะสม และคำแนะนำหลักมีข้อความไทยที่อธิบายตรงไปตรงมา คะแนน XP เป็นกิจกรรมการเรียน ไม่ใช่ระดับภาษา
- แปลคำแนะนำและปุ่มใน onboarding การประเมิน แบบฝึกหัด และหน้าจัดการข้อมูลเพิ่มเติม แต่คงโจทย์ ตัวเลือก ตัวอย่างประโยค และศัพท์ภาษาอังกฤษไว้ให้ฝึก บางข้อความรายละเอียดเนื้อหาการเรียนยังเป็นภาษาอังกฤษ
- หน้าแนะนำ `/welcome` และหน้า offline เดิมยังเป็นภาษาอังกฤษ จึงไม่ใช่การแปลเนื้อหาทั้งผลิตภัณฑ์ครบทุกหน้า

การเปลี่ยนแปลงนี้ไม่ได้ตั้งค่า Client Secret หรือ deploy ทับเว็บจริง มีไฟล์ Vercel ส่วนตัวที่ถูก Git ignore จากงานก่อนหน้า ซึ่งไม่เกี่ยวกับการเลือกภาษาและต้องไม่ commit

ตรวจสอบด้วย unit tests สำหรับการเลือกภาษาและ route หน้าแรก พร้อม Playwright บน desktop/mobile สำหรับการเปลี่ยนภาษา การจำค่าหลังรีเฟรช การคงคำตอบเดิม และการไม่แปลโจทย์ภาษาอังกฤษ

ผลตรวจในเครื่อง: production build, lint และ formatting ผ่าน, unit/component tests ผ่าน 35 ข้อ และ Playwright ผ่าน 14 กรณีบน desktop/mobile ภาพ Login และ Dashboard ภาษาไทยเก็บที่ `docs/screenshots/login-th-*.png` และ `docs/screenshots/dashboard-th-*.png` ยังไม่ได้ยืนยัน Google OAuth จริงหรือ deploy โค้ดชุดนี้ขึ้น Vercel
